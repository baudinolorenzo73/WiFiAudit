Perché alcuni strumenti non hanno il pulsante di attacco?
Rogue AP, phishing, MITM e flood possono interrompere servizi o raccogliere dati di terzi. Il pannello permette l'installazione controllata e offre documentazione, ma non costruisce campagne, portali o attacchi massivi. Usali solo in un laboratorio isolato o nello scope scritto dell'audit.

GUIDA RAPIDA
Comandi principali spiegati
Tocca Copia

      

        
Aprire questo pannello
Avvia il server solo locale e apre il browser. Non usare sudo.
./avvia_pannello.sh

        
Menu completo
Serve sudo perché monitor mode e strumenti radio richiedono privilegi.
sudo bash wifiaudit.sh --menu

        
Diagnostica
Controlla strumenti, versioni e interfacce senza effettuare un audit.
bash wifiaudit.sh --doctor

        
Test interni
Verifica le funzioni pure del programma; non usa radio né root.
bash wifiaudit.sh --self-test

        
Procedura mirata
Guida Wifite su un solo BSSID, con anteprima e conferma.
sudo bash wifiaudit.sh --guided

        
Ispezionare una cattura
Calcola hash, riconosce il formato e usa TShark se disponibile.
bash wifiaudit.sh --inspect /percorso/cattura.cap

        
Recupero offline
Prova le strategie configurate per 600 secondi sul file indicato.
sudo bash wifiaudit.sh --auto-recover /percorso/cattura.22000 --auto-seconds 600

        
Riprendere una sessione
Salta le fasi completate se input, wordlist e impostazioni coincidono.
sudo bash wifiaudit.sh --resume /percorso/session_...

        
Installare il collegamento
Aggiunge WiFiAudit al menu applicazioni dell'utente.
./avvia_pannello.sh --install

        
Archivi ZIP, 7z e RAR
Installa compressione ZIP/7z e l'estrattore multiformato Unar.
sudo apt install zip unzip 7zip unar

        
Strumenti PDF
Aggiunge visualizzazione, testo, immagini, unione e trasformazione PDF.
sudo apt install poppler-utils qpdf ghostscript evince

        
Documenti DOC e DOCX
LibreOffice Writer apre e modifica DOCX; Pandoc converte numerosi formati.
sudo apt install libreoffice-writer pandoc antiword

        
Analisi testuale catture
Mostra le opzioni di tcpdump senza catturare traffico.
tcpdump --help

        
Verifica accelerazione Hashcat
Elenca i backend OpenCL/CUDA riconosciuti; non avvia un recupero.
hashcat -I

        
Elenco wordlist Kali
Mostra i dizionari disponibili senza modificarli.
find /usr/share/wordlists -maxdepth 2 -type f -printf '%p\n'

      

      
Cosa cambia con sudo?
sudo esegue solo quel comando con privilegi amministrativi. Mentre digiti la password non compaiono caratteri: è normale. Il pannello usa sudo -k, quindi forza una nuova richiesta e non riceve né registra la password.
